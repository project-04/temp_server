
    //Please find the steps below to create a perl script and execute the same.
    
    1) Create a file named "exericse3.pl" using command $vi exercise3.pl
    2) Make sure you add the line #!/usr/bin/perl at the start line of the script.
 		   This is called as Shebang line.
    3) After writing the body of the script, save the file by pressing the ESC key followed by :w 
    4) Then quit and move to the shell prompt  by pressing the ESC key followed by :q   
    5) Execute the script by using the following command : $ perl exercise3.pl
